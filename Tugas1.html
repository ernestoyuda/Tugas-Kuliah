MATERI: HTML

HTML atau HyperText Markup Language adalah bahasa markup yang digunakan untuk menyusun struktur sebuah halaman web. HTML digunakan untuk membuat elemen seperti judul, paragraf, gambar, tautan, tabel, formulir, dan berbagai bagian lain yang tampil pada browser.

Struktur dasar dokumen HTML terdiri dari tag Seperti ini <html>, <head>, dan <body>. Bagian head berisi informasi halaman seperti judul dan style, sedangkan bagian body berisi seluruh konten yang terlihat oleh pengguna.

Dengan memahami HTML, kita memiliki dasar yang kuat untuk melanjutkan ke CSS untuk mengatur tampilan dan JavaScript untuk membuat website menjadi lebih interaktif.
